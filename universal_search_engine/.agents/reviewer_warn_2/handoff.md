## 2. Logic Chain

1. **Root Cause Resolution**: The prior defect was caused by mapping warning items directly into JSX `<li>{warn}</li>`. Because the backend returns warning objects (`WarningDto`), passing a raw object as a React child threw React invariant error `Minified React error #31` in production.
2. **Contract Alignment (R1)**: The updated `SearchWarning` interface accurately models `{ sourceName?: string; message: string }`, while `SearchResponse.warnings?: (SearchWarning | string)[]` ensures complete type safety and backward-compatibility.
3. **Safe Rendering & Defensive Invariants (R2)**: The rendering logic splits on `typeof warn === "string"`, rendering strings directly, and for objects extracts `warn?.sourceName` as a badge (`[CORE]`) and `warn?.message` as text content.
4. **Adversarial Resiliency**: If any unexpected object structure (e.g. `{ error: "foo" }`), `null`, or non-string/non-standard value is passed, the fallback `(typeof warn === "object" ? JSON.stringify(warn) : String(warn))` stringifies it safely, completely preventing any React child invariant violation under all runtime conditions.
5. **Integrity & Authenticity**: 
   - No mock data or hardcoded test values are placed in production code.
   - No dummy facade or bypass shortcuts were used.
   - Genuine React component improvements with proper Tailwind CSS styling.
