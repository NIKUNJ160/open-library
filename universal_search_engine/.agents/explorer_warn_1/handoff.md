## 2. Logic Chain

1. **Backend Payload Structure**: When an open knowledge connector throws an error, times out, or lacks an API key, the backend search service populates `warnings` with an array of objects structured as `{ sourceName: string, message: string }`.
2. **Frontend Type Deserialization**: In `frontend-dashboard/src/app/search/page.tsx`, `fetchFromApi` calls `/search?q=...` and returns the parsed JSON payload. Because TypeScript interfaces do not validate data at runtime, `resultsData.warnings` holds an array of `WarningDto` objects rather than strings.
3. **React Child Invariant Violation**: In `frontend-dashboard/src/app/search/page.tsx` line 263, the JSX mapping evaluates `<li>{warn}</li>`. In React (v19/v18), passing a plain object as a child node in JSX violates the React child invariant and triggers:
   > `Uncaught Error: Objects are not valid as a React child (found: object with keys {sourceName, message}). If you meant to render a collection of children, use an array instead.`
4. **Minified React Error #31**: In production builds, React minifies invariant errors to an error code lookup URL (`Minified React error #31`), crashing the Search Dashboard whenever warnings are returned.

---

## 3. Caveats

- No other components in `frontend-dashboard` render `warnings` (checked `app/paper/page.tsx`, `app/ask/page.tsx`, `app/collections/page.tsx`, `app/graph/page.tsx`, and `app/page.tsx`).
- For complete backward and defensive compatibility, warning rendering should handle both structured objects (`{ sourceName, message }`) and fallback raw strings (`string`), or missing properties.

## 4. Conclusion & Recommendations

### R1. Type Definition Update (`frontend-dashboard/src/app/search/page.tsx`)
Define a dedicated `SearchWarning` interface and update `SearchResponse`:
```typescript
interface SearchWarning {
  sourceName?: string;
  message: string;
}

interface SearchResponse {
  query: string;
  totalResults: number;
  executionTimeMs: number;
  results: SearchResult[];
  warnings?: (SearchWarning | string)[];
}
```

### R2. Safe JSX Rendering (`frontend-dashboard/src/app/search/page.tsx`)
Replace lines 258–267 with defensive rendering:
```tsx
            {resultsData.warnings && resultsData.warnings.length > 0 && (
              <div className="rounded-xl border border-amber-500/10 bg-amber-500/5 p-4 text-xs text-amber-400 space-y-1">
                <span className="font-bold">Partial results returned (warnings):</span>
                <ul className="list-disc pl-4 space-y-0.5">
                  {resultsData.warnings.map((warn, i) => {
                    if (typeof warn === "string") {
                      return <li key={i}>{warn}</li>;
                    }
                    return (
                      <li key={i}>
                        {warn.sourceName && (
                          <span className="font-semibold uppercase tracking-wider mr-1.5">
                            [{warn.sourceName}]
                          </span>
                        )}
                        <span>{warn.message || JSON.stringify(warn)}</span>
                      </li>
                    );
                  })}
                </ul>
              </div>
            )}
```
